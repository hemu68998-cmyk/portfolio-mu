# 何霂 · 个人作品集

产品经理 / AI 设计师个人作品集，React + Vite 实现，暗色科技风，PC 优先，版心 1700px。

## 运行

```bash
cd portfolio
npm install
npm run dev      # 本地预览
npm run build    # 生产构建
```

## 页面结构

- `Hero` 全屏首页：视频背景 + 大标题 + 导航栏 + 联系按钮
- `About` 个人经历：人物图、个人介绍、联系方式、项目数据
- `Projects` 精选项目：4 个大卡片，左右交错布局
- `Strengths` 个人优势：6 张能力卡片
- `Contact` 底部联系：整屏收尾页

## 可替换素材

把文件放进 `public/`，页面会自动使用；缺失时自动回落到程序化生成的视觉：

- `hero.mp4` — 首页视频背景（缺失时使用动态光晕 + 网格背景）
- `avatar.jpg` — 个人头像 / 人物图（缺失时显示姓名字牌）
- `work-01.jpg` ~ `work-04.jpg` — 项目配图（缺失时显示编号动效图形）

## 内容维护

所有文案、项目、优势、技能数据集中在 `src/data/content.js`，改这一个文件即可更新全站内容。
